Not a React app.

This page is one hand-written HTML file. No build step, no framework, no stylesheet of the widget's own. Its CSS is deliberately hostile — a content-box reset, a border: 0 !important on every div, and a rule that paints every button crimson-on-yellow at 22px.

The widget in the corner is unaffected, because it renders inside a shadow root with its own inlined styles. That isolation is the whole reason a client can paste this in without auditing their CSS first.

The entire integration is the tag below.

<script
  src="/widget.js"
  data-api="/api/chat"
  data-name="Northgate Assistant"
  data-accent="#3f8ee6"
  defer></script>
